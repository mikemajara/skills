# Publish

Make the point worth reading before polishing the prose. This skill owns
editorial judgment, structure, and positioning. It does not own the author's
voice.

Read the reference for the destination before drafting or rewriting:

1. Team updates and work share-outs: [references/announcement.md](references/announcement.md)
2. Essays, articles, and personal-site writing: [references/long-form.md](references/long-form.md)
3. Short social posts and threads: [references/social.md](references/social.md)

## Workflow

1. Identify the audience, intended effect, central claim, and evidence already
   present in the source.
2. State the point in one sentence. If the draft cannot support that sentence,
   expose the gap instead of inventing support.
3. Diagnose what obscures the point: chronology, disclaimers, repeated setup,
   unsupported claims, implementation detail, or a mismatch with the format.
4. Restructure for the selected destination. Preserve facts, uncertainty,
   constraints, and links.
5. Rewrite in the author's existing voice. Apply a separate voice skill only
   when the user requests one.
6. Cut anything that does not strengthen the point, evidence, or intended
   response.

Ask one short question only when missing audience, evidence, or intent would
materially change the piece. Do not invent context.

## Editorial rules

1. Lead with the strongest useful point, not the order in which events happened.
2. Give the reader a reason to care before supplying background or mechanics.
3. Separate claims from evidence and outcomes from implementation details.
4. Keep caveats that change the claim. Remove disclaimers that only delay it.
5. Make ownership visible when it matters, without turning the piece into
   self-promotion.
6. Match the depth, pacing, and close to the destination. Not every piece needs
   a call to action.
7. Prefer one developed idea over several underdeveloped ones.
8. Preserve the author's actual level of confidence. Do not manufacture
   certainty, novelty, conflict, or enthusiasm.

## Output

If reviewing an existing draft, return:

### What to fix

A short numbered diagnosis with quoted fragments where useful.

### Rewrite

One copy-paste-ready version for the requested destination.

If the user asks for a new draft, return only the draft unless assumptions or
missing evidence need to be surfaced first.

## Self-check

1. Can the central point be stated in one sentence?
2. Does the opening earn the next paragraph or post?
3. Is every claim supported by the supplied material?
4. Is background shorter than the idea it supports?
5. Does the structure fit the destination?
6. Did the rewrite preserve uncertainty and meaning?
7. Can anything else be cut without weakening the piece?
