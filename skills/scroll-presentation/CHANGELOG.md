# Scroll presentation changelog

Versions apply to this skill and its bundled kit, scripts, references, and assets, not to other skills. The history below summarizes an earlier, undated entry in the [repository changelog](../../CHANGELOG.md); that entry was not a separate versioned release of Scroll presentation.

## 0.1.0 — 2026-11-03

Initial independent skill version.

- Build one offline, mobile-first HTML scroll story with pinned scenes, morphing objects, snap-to-step behavior, and reduced-motion fallback.
- Bundle a GSAP ScrollTrigger scene kit, starter template, vendored runtime, scaffold/build script, optional Playwright QA script, and design, API, testing, and worked-example references.

No migration is required for existing installations.
