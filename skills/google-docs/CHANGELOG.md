# Google Docs changelog

Versions apply only to this skill. The history below summarizes earlier, undated entries in the [repository changelog](../../CHANGELOG.md); those entries were not separate versioned releases of Google Docs.

## 0.1.0 — 2026-11-03

Initial independent skill version.

- Connector-agnostic guidance for creating, formatting, editing, commenting on, suggesting changes in, and reviewing Google Docs.
- For collaborative work, use `collaboration` in the actual Doc and its threads; apply shared comment-size checks and Drive anchoring caveats.

No migration is required for existing installations.
