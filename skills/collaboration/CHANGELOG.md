# Collaboration changelog

Versions apply only to this skill. The history below summarizes earlier, undated entries in the [repository changelog](../../CHANGELOG.md); those entries were not separate versioned releases of Collaboration.

## 0.1.0 — 2026-11-03

Initial independent skill version.

- Collaborate in the shared document, sheet, or page and its comment threads; choose an editing scope for the session and sign agent comments and replies.
- Preflight final signed comments against size limits, including Unicode boundaries; document Sheets, Drive, and Notion constraints and provide an offline size checker with deterministic tests.

No migration is required for existing installations.
